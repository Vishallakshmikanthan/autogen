# Model-Based Reinforcement Learning: Dyna-Q

## 1. Theory & Mathematical Definition
Dyna-Q integrates online trial-and-error learning with simulated experience generated by an internal learned model of the environment. Acting, direct model-free learning, model learning, and planning occur simultaneously within every transition step.

## 2. Dyna-Q Architecture
At state $S$, execute action $A$, observe $R, S'$:
1. **Direct RL:** $Q(S, A) \leftarrow Q(S, A) + \alpha [R + \gamma (1 - d) \max_a Q(S', a) - Q(S, A)]$.
2. **Model Learning:** $\hat{\mathcal{M}}(S, A) \leftarrow (R, S', d)$.
3. **Planning Loop:** Repeat $N$ times:
   - Sample previously visited state $s \sim \mathcal{S}_{\text{visited}}$.
   - Sample previously taken action $a \sim \mathcal{A}(s)$.
   - Query internal model: $(r, s', d') \leftarrow \hat{\mathcal{M}}(s, a)$.
   - Planning update:
     $$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma (1 - d') \max_{a'} Q(s', a') - Q(s, a)]$$

## 3. Computational Trade-offs & Sample Efficiency
- Time per step: $O(N)$ where $N$ is the number of planning backups.
- Dramatically increases sample efficiency by propagating reward signals throughout the state graph during simulation without requiring extra physical interactions.

## 4. Verification Strategy
- Demonstrate that Dyna-Q with $N=10$ achieves optimal policy in $> 3\times$ fewer environmental interactions than pure Q-learning ($N=0$) on GridWorld.
