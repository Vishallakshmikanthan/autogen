# Informed Heuristic Search Algorithms (Greedy, A*, Weighted A*, IDA*)

> **Module:** M06 — Search Algorithms and Problem Solving (SYS-06, Gate 2)  
> **Source:** Hart, Nilsson & Raphael (1968); Russell & Norvig, AIMA (4th Ed.), Chapter 3.

---

## 1. Theory & Mathematical Definition

Informed search uses an evaluation function $f(n)$ incorporating a heuristic estimate $h(n)$ of the remaining cost from node $n$ to the closest goal:
$$h: \mathcal{S} \to [0, \infty), \quad h(g) = 0 \; \forall g \in \mathcal{G}$$

| Algorithm | Evaluation Function $f(n)$ | Optimality Condition |
|---|---|---|
| **Greedy Best-First** | $f(n) = h(n)$ | Not optimal |
| **A\* Search** | $f(n) = g(n) + h(n)$ | Optimal if $h$ is admissible (tree) or consistent (graph) |
| **Weighted A\*** | $f_w(n) = g(n) + w \cdot h(n), \; w \ge 1.0$ | $\epsilon$-suboptimal: $C \le w \cdot C^*$ |
| **IDA\*** | Depth-first thresholded on $f(n) \le \text{bound}$ | Optimal if $h$ is admissible |

---

## 2. Assumptions

1. **Admissible Heuristic:** $0 \le h(n) \le h^*(n)$ for all states $n$.
2. **Consistent Heuristic (Monotonicity):** $h(n) \le c(n, a, n') + h(n')$ for all successors $n'$.
3. **Non-negative Step Costs:** $c(n, a, n') \ge \epsilon > 0$.
4. **Finite Branching Factor:** The action set $A(s)$ is finite.

---

## 3. Equations & Mathematical Model

The evaluation function balances path cost $g(n)$ and heuristic estimate $h(n)$:
$$f(n) = g(n) + h(n)$$
where:
$$g(n) = \sum_{i=1}^k c(s_{i-1}, a_i, s_i)$$

### Admissibility Condition
A heuristic $h(n)$ is **admissible** if it never overestimates the true minimal cost $h^*(n)$ to reach the goal:
$$\forall n \in \mathcal{S}, \quad 0 \le h(n) \le h^*(n)$$

### Consistency (Monotonicity) Condition
A heuristic $h(n)$ is **consistent** if for every node $n$ and every successor $n'$ generated by action $a$:
$$h(n) \le c(n, a, n') + h(n')$$
By the triangle inequality:
$$f(n') = g(n') + h(n') = g(n) + c(n, a, n') + h(n') \ge g(n) + h(n) = f(n)$$

---

## 4. Weighted A* Bounded Suboptimality

Weighted A* weights the heuristic:
$$f_w(n) = g(n) + w \cdot h(n), \quad w > 1$$
**Suboptimality Theorem:**  
If $h(n)$ is admissible, the solution cost $C$ found by Weighted $A^*$ satisfies:
$$C^* \le C \le w \cdot C^*$$

---

## 5. Computational Complexity

- **Time Complexity:** $\mathcal{O}(b^d)$ in the worst case, where $b$ is the branching factor and $d$ is optimal solution depth. With an ideal heuristic ($h = h^*$), time is $\mathcal{O}(d)$.
- **Space Complexity:** $\mathcal{O}(b^d)$, as all generated states reside in the open priority queue and closed visited dictionary.

---

## 6. Implementation Notes

- When consistency does not hold, our `AStarSearch` implementation inspects discovered paths against `best_g[state]`. If an alternate path yields $g_{\text{new}} < \text{best\_g}[s]$, the node is reopened into the open set, preserving optimality even under non-monotonic admissible heuristics.

## 7. Verification Strategy & Test Oracles

- **Optimality against SciPy Oracle:** In `tests/integration/test_search_dijkstra_oracle.py`, A* with scaled Manhattan heuristic matches SciPy Dijkstra exactly on 500 random grids with 0 discrepancies.
- **Inadmissible Heuristic Trap:** Demonstrates in `tests/unit/test_heuristics.py` that an inflated heuristic ($h = 1000$) causes A* to pick a suboptimal path ($C = 10.0 > C^* = 8.0$), proving the verification oracle test has teeth.
- **Weighted A\* Bound:** Tested in `tests/unit/test_informed_search.py` verifying $C^* \le C \le w \cdot C^*$ across weights $w \in \{1.2, 1.5, 2.0\}$.

---

## 8. Known Limitations

- **Memory Bottleneck:** Because A* retains all open and closed nodes in memory, exponential state space explosion can exhaust RAM on large unstructured grid topologies.
- **Heuristic Sensitivity:** Performance degrades to Uniform Cost Search if the heuristic is uninformative ($h(n) = 0$).
