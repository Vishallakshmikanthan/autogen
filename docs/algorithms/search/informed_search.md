## 1. Theory & Mathematical Definition

Informed search uses an evaluation function $f(n)$ incorporating a heuristic estimate $h(n)$ of the remaining cost from node $n$ to the closest goal:
$$h: \mathcal{S} \to [0, \infty), \quad h(g) = 0 \; \forall g \in \mathcal{G}$$

| Algorithm | Evaluation Function $f(n)$ | Optimality Condition |
|---|---|---|
| **Greedy Best-First** | $f(n) = h(n)$ | Not optimal |
| **A\* Search** | $f(n) = g(n) + h(n)$ | Optimal if $h$ is admissible (tree) or consistent (graph) |
| **Weighted A\*** | $f_w(n) = g(n) + w \cdot h(n), \; w \ge 1.0$ | $\epsilon$-suboptimal: $C \le w \cdot C^*$ |
| **IDA\*** | Depth-first thresholded on $f(n) \le \text{bound}$ | Optimal if $h$ is admissible |

---

## 2. Admissibility & Consistency Derivations

### Admissibility Condition
A heuristic $h(n)$ is **admissible** if it never overestimates the true minimal cost $h^*(n)$ to reach the goal:
$$\forall n \in \mathcal{S}, \quad 0 \le h(n) \le h^*(n)$$

**Theorem (A\* Optimality with Admissibility):**  
If $h$ is admissible, $A^*$ tree search is guaranteed to return an optimal solution.

### Consistency (Monotonicity) Condition
A heuristic $h(n)$ is **consistent** if for every node $n$ and every successor $n'$ generated by action $a$:
$$h(n) \le c(n, a, n') + h(n')$$
By the triangle inequality:
$$f(n') = g(n') + h(n') = g(n) + c(n, a, n') + h(n') \ge g(n) + h(n) = f(n)$$
Thus, $f(n)$ is monotonically non-decreasing along any path, guaranteeing that whenever a node is expanded in graph search, its $g$-cost is optimal without requiring reopening.

### Reopening Handling
When consistency does not hold, our `AStarSearch` implementation inspects discovered paths against `best_g[state]`. If an alternate path yields $g_{\text{new}} < \text{best\_g}[s]$, the node is reopened into the open set, preserving optimality even under non-monotonic admissible heuristics.

## 3. Weighted A* Bounded Suboptimality

Weighted A* weights the heuristic:
$$f_w(n) = g(n) + w \cdot h(n), \quad w > 1$$
**Suboptimality Theorem:**  
If $h(n)$ is admissible, the solution cost $C$ found by Weighted $A^*$ satisfies:
$$C^* \le C \le w \cdot C^*$$
*Proof Outline:*  
Let $n^*$ be a node on the optimal path currently on the frontier.
$$f_w(n^*) = g(n^*) + w \cdot h(n^*) \le w \cdot (g(n^*) + h(n^*)) = w \cdot f(n^*) \le w \cdot C^*$$
Any goal node $g$ popped before $n^*$ satisfies:
$$C = f_w(g) \le f_w(n^*) \le w \cdot C^*$$
